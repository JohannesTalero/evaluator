# progreso/

Notas de traspaso entre sesiones o entre agentes.

Cada archivo se genera con `make traspaso` y lleva el ID de la tarea
(por ejemplo `d1.2.md`). Contiene: rama, commits, archivos tocados,
estado de `make check-rapido`, y secciones para completar a mano:
**Qué falta** y **Siguiente paso concreto**.

Estos archivos siempre están permitidos por CI (alcance.py los excluye).
